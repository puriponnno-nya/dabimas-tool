# dabimas-tool — ダビマス能力判定ツール v1

ダビマス（Derby Stallion Masters）の所有馬の能力を、コメント文と能力ランクから判定・記録するツールです。
iPhone・Safariで使う1画面の静的ツールです。追加課金・有料API・サーバーは使いません。

## 目的（v1）

- 馬レコードの作成・一覧・編集・削除（馬名、性別、成長タイプ、SP/STランク、コメント文の貼り付け、メモ）
- コメント文の分類表示（素質 tal／将来 fut／特徴 fea／期待と条件 exp）
- ランクと素質・タイトル文からの SP/ST 候補範囲の参考表示（**参考・未検証**と明記）。タイトル帯（牡160〜179／牝150〜179、180以上は「海外も視野」）と、後光275以上・馬神300以上は「なりうる（参考）」の表示のみで、確定値としては表示しない
- ブラウザ内保存（localStorage）と JSON 書き出し・読み込み
- **定型文の貼り付け**：「定型文を貼り付ける」欄に馬体解析の定型文をまるごと貼ると、馬名・年齢・解析時期・解析タブ・所属・SP/ST/根性/気性/体質ランク・メモリ・脚質・距離適性・適応力・博士コメント・特徴・目標レースを自動で読み取ってフォームに入れる。読み取れなかった項目は空欄のまま手入力できる。個別入力もそのまま残っている

## スピード・スタミナ測定について（理論の出典）

- **v1はスピード・スタミナの数値測定をしていません。**やっているのは、ランク（A〜E）とコメント文から SP/ST の候補範囲を参考表示することだけです。測定用コメントの検出のみで、数値・到達率は判定しません。「BC登録はまだ先ですね」と「BC登録は　まだ先ですね」はスペースの有無で区別する。
- **測定メモによる絞り込み（参考・未検証）**：入厩前（または入厩後・未調教）のランクとコメントを記録し、馬を選んで調教した結果（調教本数、変わった内容：コメント変化／スペースあり／ランク変化）を測定メモに1件ずつ追加できます。その記録から、測定用コメントとその時点のSPランク、メモリを使って、潜在SPの候補範囲を参考として絞った表示を出します（例：メモリ2などで「BC登録は　まだ先ですね」（スペースあり）なら到達率75%以上、「完成まであと一息」なら85%以上）。数値は断定しません。すべてユーザー検証による推定・未確定です。詳しくは `docs/rules.md` の「測定の絞り込み（測定メモ）」を見てください。
- **参考表記は折りたたみ式**：理論・参考の表示が長くなるため、画面の参考・未検証の理論と注意は折りたたみ式で、基本は非表示です。開いたときだけ表示されます。測定ツールを調教本数の理論でアップデートできるまでは、基本は非表示のままです。
- 将来の測定に使うかもしれない記録として、レコードに任意入力の「調教本数」欄があります。仮説メモ（入厩前と入厩後の調教本数によるコメントの推移で測るはず。今の最適は未確定）は `docs/rules.md` を見てください。調教本数は測定には使わず、記録として保存するだけです。
- 候補範囲に使っている理論は、2018年資料（https://dbmsmemo.blogspot.com/2018/02/blog-post_20.html）などを参考にした**参考・未検証**です。ランク範囲 A 100〜・B 85〜99・C 70〜84・D 55〜69・E 〜54、「これは凄い素質の馬ですね」→ SP・ST 各81以上、「将来はいくつかのタイトルも狙えるでしょうね」→ SP＋ST ≧160（牡）／≧150（牝）（タイトル帯は牡160〜179／牝150〜179、180以上は「海外も視野」）、後光は合計275以上、馬神は300以上として「なりうる（参考）」だけを表示します。Ver.4.0.0（2023-10-26）後のPerplexity調査（2026-11-14）では、公開ツールや2025〜2026年の実馬報告で同じ区切りが使われていると整理されましたが、公式の保証はなく、2026年11月まで不変だったとも断定できません。ランク区切りは変えず、すべて参考・未検証として扱います。新しい理論や数値は作っていません。詳しくは `docs/rules.md` を見てください。
- 馬体解析レポートの3段構造、入厩直後のスタミナは最大値の半分という注意、BC印比較によるスピード測定は参考情報で、v1では測定機能として実装していません。

## 対象外（v1ではやらない・後回し）

- 配合計画の管理（後回し。旧仕様 v1.0 の続きは v2 以降で検討）
- 配合シミュレーション、血統図、種牡馬DB照合
- **スクショOCR**：このツールはスクショを直接読み取りません。旧ツールもスクショ読み取りはしていませんでした。Perplexityではファイルのアップロード上限でスクショ読み取りができなかったため、v1は下の「コメント文の用意のしかた」のワークフローで判定します。スクショからの自動読み取りは後回しです
- スピスタ（スピード／スタミナ）の数値測定：測定用コメントの検出と、測定メモによる絞り込みの参考表示のみで、数値の断定はしません
- Notionデータベース連携：判定結果の保存先は未設計です（新スキーマは要承認のため）

## データ方針

- **仮データのみ**です。実牧場データは入れません。
- 保存はこの端末のブラウザ内（localStorage）のみです。サーバーには送りません。

## コメント文の用意のしかた（推奨ワークフロー）

1. iPhoneのショートカットで、ゲームのスクショ（馬体解析などのコメント画面）を読み込む
2. Googleアプリで文字起こしする
3. 文字起こしした文を、このツールのコメント欄に貼り付ける

文字起こしの精度は完璧ではありません。そのためこのツールは、完全一致ではなく正規化（全角／半角・空白・改行の除去、よくあるゆらぎの吸収）＋部分一致・あいまい照合で分類します。照合できなかった文は「未分類」として表示し、手で分類を選び直せます。

## 使い方

1. `index.html` を開きます（ローカルで開く場合は `file://` でも動きます。`data/*.json` が読めない場合はアプリ内蔵の同じ内容を使います）。
2. **定型文を貼る場合**：「定型文を貼り付ける」欄に馬体解析の定型文をまるごと貼り、「✨ 定型文から読み取る」を押します。馬名・ランク・コメントが自動でフォームに入ります。読み取れなかった項目は空欄のままなので手で入れてください。
3. 馬名・性別・SP/STランクを入力し、上のワークフローで用意したコメント文を貼り付けます。
4. 「判定して登録」を押すと、コメント分類と SP/ST 候補範囲が表示され、一覧に保存されます。
4. 一覧の馬をタップすると詳細・編集・削除ができます。
5. 「JSON書き出し」で全件バックアップ、「JSON読み込み」で全件置き換え（検証あり。不正なJSONは拒否して既存データは変えません）。
