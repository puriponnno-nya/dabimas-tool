# ダビマス能力判定ツール 仕様 v2（v1）

## 目的

ダビマスの所有馬の能力を、コメント文と能力ランクから判定・記録する。
**能力判定を先に作る。配合計画は後回し。**

## 対象

- iPhone・Safariで使う1画面の静的ツール（`index.html`＋`styles.css`＋`app.js`）
- 追加課金・有料API・サーバーなし
- 仮データのみ。実牧場データは入れない

## 入力の前提（重要）

- コメント欄には、**iPhoneショートカットでスクショを読み込み、Googleアプリで文字起こしした文を貼り付ける**ことを前提とする。
- スクショの直接読み取り（OCR）はしない。Perplexityではファイルのアップロード上限でスクショ読み取りができなかったため、このワークフローになった。
- 文字起こしの精度は完璧ではない。そのため判定は完全一致ではなく、正規化＋部分一致・あいまい照合で行う（`docs/rules.md` 参照）。

## 機能（v1）

1. 馬レコードの作成・一覧・編集・削除
   - 項目：馬名（必須）、年齢、性別（牡／牝／セン／不明）、解析時期、解析タブ、解析時所属、メモリ、成長タイプ（メモリの数字＝バーの目盛り 1〜6。1＝最も早寄り、6＝最も遅寄り。対応：1→早寄り、2→早寄りの中間、3→中間、4→遅寄りの中間、5→遅寄り、6→遅寄り（最遅）。数字（growthNum）とことば（growth）の両方を保存・表示し、バー表示も出す）、SPランク（A〜E／未入力）、STランク（A〜E／未入力）、根性・気性・体質ランク（A〜E／未入力）、脚質、距離適性、適応力、博士コメント・特徴・目標レース（定型文の3つの文章）、コメント文（貼り付け）、メモ、手修正（未分類文の手分類）
   - 成長タイプは推定計算には使わない。表示のみ（例：成長タイプ 2/6 早寄りの中間 ■■□□□□）
   - ID・作成日時は不変、更新日時で更新する
2. 定型文の貼り付け読み取り（`parsePasted`）
   - 「定型文を貼り付ける」欄に、馬体解析の定型文をまるごと貼る。「馬名：」「年齢：」「解析時期：」「解析タブ：」「解析時所属：」「スピード：」「スタミナ：」「根性：」「気性：」「体質：」「メモリ：」「脚質：」「距離適性：」「適応力：」の行を読み取り、ランクは A〜E のみ採用する
   - 「博士コメント：」「特徴：」「目標レース：」の見出し以降は複数行の文章として読み取り、3つの欄と判定用のコメント欄（3つをまとめたもの）に入れる
   - **「メモリ：N」は成長タイプの数字。**N が 1〜6 なら成長タイプにも反映する（1→早寄り、2→早寄りの中間、3→中間、4→遅寄りの中間、5→遅寄り、6→遅寄り（最遅））。メモリ欄自体も残す。メモリ欄に 1〜6 を手で入れたときも成長タイプに反映する
   - 旧レコードとの互換性：成長タイプがことばだけの旧レコード（growthNum なし）も読める。ことばから数字を逆引きして表示する（例：「早寄りの中間」→2/6）。growthNum が 1〜6 以外のJSONは読み込み時に拒否する
   - 全角・半角の「：」「:」どちらでも読む。読み取れなかった項目は空欄のまま手入力できる。読み取れた項目と読めなかった項目をメッセージで表示する
   - 従来の個別入力も残す。定型文を使わずに直接入力してもよい
2. コメント分類の表示：素質 tal／将来 fut／特徴 fea／期待と条件 exp
3. 測定用コメント3種の検出のみ（数値・到達率は判定しない）
4. SP/ST 候補範囲の参考表示（ランク範囲＋素質・タイトル文の条件。**参考・未検証**と明記）
5. ブラウザ内保存（localStorage、キー `dabimas-ability-v1`）
6. JSON書き出し・読み込み
   - 書き出し：全件。読み込み：全件置き換えのみ。検証あり（version 1、レコード形式、ID重複を検査）
   - 不正なJSONは拒否して、既存データは変えない
7. 未分類文の表示と手修正
   - 照合できなかった文は「未分類」として表示する
   - 未分類の文ごとに分類（tal／fut／fea／exp）を手で選べる。選ぶとその場で判定に反映され、保存すると手修正も一緒に保存される
   - コメント文を編集すると手修正はリセットされる（原文が変わるため）

## 対象外（v1）

- 配合計画の管理・配合シミュレーション・血統図・種牡馬DB照合
- スクショOCR、スピスタの数値測定
- Notionデータベース連携（判定結果の保存先は未設計。新スキーマは要承認）
- 検索・並べ替え（更新日時順の一覧のみ）

## データ

- `data/comments.json`：コメント対応表 CMT／CMX（旧プレビューから統合）。全件網羅ではない
- `data/ranks.json`：ランク範囲・素質・タイトル条件（2018年資料由来・参考・未検証）
- `app.js` には `data/*.json` と同じ内容の内蔵コピーがある（`file://` で開いたときに JSON が読めない場合の予備。正本は `data/*.json`）

## 制約

- 未確認のゲーム仕様・数値は推測実装しない。推定と確定、現在能力と潜在能力を区別する
- 推定結果は「参考」と明記し、確定値として扱わない
